# right-lane-site

Public pages of the Right Lane app, served by GitHub Pages: https://right-lane.be/

- `index.html`, `style.css`, `script.js`, `i18n.js`, `img/`, `fonts/`: the landing page that presents the app, in French, Dutch and English (language menu in the header; `i18n.js` holds the Dutch and English texts). Its source is `website/` in the app repository: edit it there, then copy these files here.
- `fr/terms.md`: terms of use
- `fr/privacy.md`: privacy policy
- `nl/terms.md`, `nl/privacy.md`, `en/terms.md`, `en/privacy.md`: the same pages in Dutch and English (the French version is the reference)
- `fr/right-lane-guide.pdf`: printable guide with all the app content, generated in the app repository by `python scripts/export_guide.py`
- `nl/right-lane-guide.pdf`, `en/right-lane-guide.pdf`: the same guide in Dutch and English, generated by `python scripts/export_guide.py --locale nl` or `--locale en`

The app downloads these Markdown files from `raw.githubusercontent.com` and renders them itself, so editing a file here updates the app without a new release. Each language of the app has its own folder (`fr/`, `nl/`, `en/`).

Syntax understood by the app: `#` and `##` headings, paragraphs, `- ` lists, `**bold**` and `[text](url)` links. Links to the other page (`https://right-lane.be/fr/privacy.html`) open it inside the app. Keep the "Version du …" date up to date.
